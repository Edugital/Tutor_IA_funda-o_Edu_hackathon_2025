# Modelo de transparência para estudantes

## Uso de inteligência artificial nesta atividade

Esta atividade pode utilizar uma ferramenta de inteligência artificial para apoiar a elaboração do feedback.

A ferramenta:

- não define automaticamente sua nota;
- não publica feedback sem revisão de uma pessoa responsável;
- utiliza a rubrica e as orientações da atividade como referência;
- pode cometer erros e suas sugestões podem ser alteradas ou descartadas;
- não deve substituir o diálogo com o professor.

## Controle humano

O feedback oficial é publicado somente depois de uma decisão humana. A pessoa avaliadora pode:

- escrever o feedback sem usar a sugestão;
- aceitar a sugestão;
- editar a sugestão;
- substituir completamente a sugestão.

## Seus direitos

De acordo com as políticas da instituição e a legislação aplicável, você pode:

- pedir explicação sobre o feedback;
- solicitar revisão humana;
- contestar a avaliação pelos canais institucionais;
- solicitar informações sobre os dados utilizados;
- exercer direitos de acesso, correção, exportação ou exclusão quando aplicáveis.

## Dados

A instituição deve informar:

- quais dados são processados;
- qual fornecedor ou infraestrutura é utilizada;
- por quanto tempo os dados são mantidos;
- se os dados são enviados para fora da instituição;
- como solicitar suporte ou revisão.

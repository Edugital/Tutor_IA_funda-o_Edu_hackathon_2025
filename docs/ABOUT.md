# Sobre o Tutor IA

**Tutor IA** é um plugin de feedback de tarefa para Moodle que coloca a inteligência artificial sob supervisão docente (**Human in Control**).

Nasceu no ecossistema do edital de IA da Fundação Itaú, via Instituto Saber, e foi prototipado/fortalecido no **EduHackathon 2025** (Saber Social + EBAC + Edugital). Hoje integra o pacote white-label **EBAC LMS** como componente opcional, pinado por tag.

## Para quem é

- Professores e designers instrucionais que querem rascunho de feedback alinhado a rubricas, sem abdicar da nota e do juízo pedagógico.
- Escolas e redes que precisam de transparência, Privacy API e automação **off-by-default**.

## O que não é

- Não é um “corretor automático” de notas.
- Não é um chatbot genérico no LMS.
- Não embute chaves de API no repositório.
